# Coffer whitepaper

The technical whitepaper for Coffer, a protocol where Ethereum validators issue bonds backed by their own stake.

- Read it online at [docs.coffer.bond/whitepaper](https://docs.coffer.bond/whitepaper) or open `whitepaper.pdf` here.
- The source is `whitepaper.tex`.
- The smart contracts live in [coffer-smart-contracts](https://github.com/blockroad-doo/coffer-smart-contracts) and [coffer-marketplace](https://github.com/blockroad-doo/coffer-marketplace).

## Build the PDF

With a TeX Live installation, run

    latexmk -pdf whitepaper.tex
